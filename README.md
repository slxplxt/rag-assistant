# Banking RAG Assistant — MVP 1.0

Учебный RAG-сервис для вопросов по одному банковскому документу: Т-Банк,
расчётная карта, ТПС 3.0 (рубли РФ). Возвращает ответ и найденные фрагменты
с именем файла и номером страницы. Интерфейс MVP — FastAPI и Swagger `/docs`.

ВТБ и сравнение банков исключены из версии 1.0 после двух ограниченных
экспериментов: извлечение цены улучшилось, но условия бесплатности не вошли
в top-3. Запросы с явным упоминанием ВТБ возвращают `unsupported` без LLM.
Проект отвечает по загруженному документу и не утверждает актуальность тарифов.

## Стек и архитектура

Python 3.12, PyMuPDF, LangChain, sentence-transformers, Chroma, GigaChat,
FastAPI, Pydantic, pytest.

```text
PDF → текст по страницам → чанки (600/100 токенов cl100k_base)
    → rubert-tiny2, нормализованные embeddings → локальная Chroma
POST /ask → валидация → dense top-3 → prompt с контекстом
          → GigaChat → answer + status + sources
```

`prepare_data.py` строит индекс; `query_data.py` инициализирует ресурсы;
`rag_service.py` обрабатывает запрос; `main.py` предоставляет API.
Ресурсы загружаются один раз в lifespan приложения. История диалога не используется.

## Установка (PowerShell)

```powershell
git clone https://github.com/slxplxt/rag-assistant.git
cd rag-assistant
py -3.12 -m venv venv
.\venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python -m pip check
Copy-Item .env.example .env
```

Команды относятся к версии исходников с этими изменениями; локальные изменения
ещё не опубликованы автоматически. Если политика PowerShell запрещает активацию,
используйте `venv\Scripts\python.exe` вместо `python`.

В `.env` заполните `GIGACHAT_CREDENTIALS` своим ключом авторизации GigaChat.
Не помещайте ключ в код, запросы к `/ask` или Git. Модель по умолчанию — GigaChat.
Первый запуск требует сети для загрузки embeddings и словаря tiktoken.

TLS-проверка включена по умолчанию: `GIGACHAT_VERIFY_SSL_CERTS=true`.
Используется системное хранилище доверия; при необходимости задайте
`GIGACHAT_CA_BUNDLE` — путь к доверенному PEM bundle.

Только для локального тестирования допускается явное исключение в `.env`:

```dotenv
GIGACHAT_VERIFY_SSL_CERTS=false
```

Это небезопасно: подлинность сервера не проверяется, возможен перехват credentials
и запросов. Не используйте исключение для публичного развёртывания.
Оно относится только к клиенту GigaChat, не изменяет глобальную настройку HTTP
и при `false` игнорирует CA bundle. При `true` поддержка bundle сохраняется.
Допустимы только `true` и `false` (без учёта регистра); опечатки вызывают ошибку.
Локальный `.env` не публикуется, в `.env.example` оставлено безопасное значение.

## Документ и индекс

Нужен PDF Т-Банка «Расчётная карта. Тарифный план ТПС 3.0 (рубли РФ)».
Получите его в разделе документов/тарифов Black на официальном сайте Т-Банка
и сохраните как `data/tbank_tariff.pdf` (папку `data` при необходимости создайте).
PDF не входит в репозиторий. Для точного повторения исторических результатов
нужен исходный снимок, а не любая текущая редакция документа.

Проверенный снимок: 1 страница, маркировка `T-TPS-3.0-250116`, SHA-256:

```text
d4b0edf7dfdc28baf7ceca3eade8166adda7abd830b6ff07ba06f40e393c4d19
```

Проверка файла и создание индекса:

```powershell
Get-FileHash data/tbank_tariff.pdf -Algorithm SHA256
python -m evaluation.validate_dataset
python prepare_data.py
```

Если редакция другая, текущая разметка может не соответствовать ей. Не переносите
результаты на другой документ. Постоянный проверенный URL именно архивного снимка
пока не установлен — это ограничение воспроизводимости исходных данных.

Индекс по умолчанию: `vector_db_tbank_v1`. Скрипт отказывается перезаписывать
существующую папку: для пересборки задайте новый `DB_DIR` и используйте его при
запуске API. Индексы старых экспериментов не удаляются. При запуске сервис
отклоняет индекс с банком, отличным от `tbank`, или без метаданных банка.

## Запуск и пример

```powershell
python -m uvicorn main:app --host 127.0.0.1 --port 8000
```

Откройте [Swagger UI](http://127.0.0.1:8000/docs). `GET /health` возвращает
`{"status":"ok"}` после успешной инициализации; это не проверка доступности GigaChat.

```powershell
$body = @{question = "Сколько стоит обслуживание Т-Банка?"} | ConvertTo-Json
Invoke-RestMethod http://127.0.0.1:8000/ask -Method Post -ContentType "application/json; charset=utf-8" -Body ([System.Text.Encoding]::UTF8.GetBytes($body))
```

Фрагмент реального HTTP 200 ответа на вопрос
«Сколько стоит обслуживание Т-Банка при невыполнении условий бесплатности?»
(поле `sources` опущено для краткости):

```json
{
  "answer": "[Источник 1, страница: 1]\nПри отсутствии условий бесплатного обслуживания (наличия неснижаемого остатка на вкладах, накопительных счетах, картсчетах и брокерских счетах не менее 50 000 рублей за расчетный период или наличия кредита, выданного на картсчет), плата за обслуживание составляет **99 рублей в месяц**.",
  "status": "answered"
}
```

Полный ответ с источниками и результаты семи запросов сохранены в
`evaluation/results/final_api_smoke.json`. Проверка выполнена локально с
`GIGACHAT_VERIFY_SSL_CERTS=false`.

`content` в реальном ответе содержит найденный чанк целиком. Источники — контекст
поиска, а не независимая проверка каждого утверждения.

Контракт:

- `answered`: LLM вернула текст; он может содержать отказ из-за недостатка данных.
  Статус не гарантирует фактическую правильность или достаточность evidence.
- `no_context`: поиск вернул пустой список; LLM не вызывалась.
- `unsupported`: явно назван ВТБ или сравнение с ВТБ; LLM не вызывалась.
- HTTP 422: пустой/пробельный вопрос, неверный тип или более 1000 символов после trim.
- HTTP 502: ошибка провайдера генерации; HTTP 500: прочая ошибка обработки.
  В ответ и прикладной лог не выводятся подробности исключения.

Без явно указанного банка вопрос трактуется в контексте единственного документа.
Распознавание всех возможных названий других банков не реализовано; ограничения
также заданы в prompt, но это не гарантированная классификация намерений.

## Проверки и оценка

```powershell
python -m pytest tests -q
python -m evaluation.validate_dataset
python -m evaluation.run_mvp_checks
# Необязательно: три платных/квотируемых обращения к GigaChat
python -m evaluation.run_mvp_checks --generate
```

Последняя команда сохраняет `evaluation/results/mvp_smoke.json` и завершается
с ненулевым кодом при ошибке генерации. Она не вычисляет автоматическую точность
ответов: их следует сверить с PDF вручную.

Датасет: 10 вопросов по одному PDF, из них 7 answerable и 3 unanswerable.
Повторная проверка retrieval в MVP дала mean evidence Recall@1 = 0.7143,
Recall@2 = 1.0, Recall@3 = 1.0. В индексе всего три чанка: top-3 возвращает
весь корпус, поэтому это smoke check, а не доказательство масштабируемого поиска.
Проверка источников подтверждает файл и банк, evidence проверяется по страницам.

Исторические отчёты от октября 2026 для прежней версии:
faithfulness 0.9714 на 7 ответах; factual correctness 0.824 на 5 из 7
(две ошибки парсинга); корректные отказы 3/3 по ручной разметке.
Это не новая оценка генерации и не показатели системы с двумя банками.
Для исторического Ragas runner нужны `requirements-eval.txt`; повторная дорогая
оценка для MVP не требуется.

Статус проверки выпуска: локальная индексация выполнена, 40 тестов проходят,
`pip check` не обнаруживает конфликтов.
Реальный FastAPI `/ask` проверен: цена и условия бесплатности Т-Банка, отказ при
отсутствии срока доставки, `unsupported` для ВТБ/сравнения, HTTP 422 для пустого
и пробельного ввода. Ошибки провайдера и отсутствие утечек проверены тестами.
Live-запуск использовал явно заданное локальное TLS-исключение. Системное
хранилище в проверенном окружении не подтверждает цепочку GigaChat; для работы
с проверкой нужен доверенный CA bundle. Чистая установка с нуля не проверена.
Предыдущий `mvp_smoke.json` сохраняет неудачную TLS-попытку как исторический
результат; успешный финальный HTTP-прогон находится в `final_api_smoke.json`.

## Эксперимент ВТБ и границы проекта

Результаты последнего эксперимента сохранены в `evaluation/results/vtb_points_experiment.json`.
Код последней гипотезы сохранён только локально в `experiments/` и исключён
из публикации вместе с временными файлами и индексами. Отчёт эксперимента включён
для объяснения принятого ограничения MVP.

`app.py` и `evaluate_retrieval.py` — оставшиеся исторические файлы вне MVP;
их запуск не поддерживается. Локальные `test.py` и `evidence_judge.py` исключены
из публикации. Streamlit не входит в requirements MVP.
Отдельный CLI-чат удалён из query_data.py.

Известные ограничения: маленький корпус, отсутствие проверки цитат на уровне
утверждений, зависимость от качества PDF-текста и внешнего LLM, отсутствие
авторизации/лимитов для публичного API. Запуск рассчитан на локальную демонстрацию.
Разработка MVP завершена в этих границах; расширение корпуса не входит в выпуск.
