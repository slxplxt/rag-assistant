# RAG Assistant 

AI-ассистент для ответов на вопросы по банковским тарифам с удобным **веб-интерфейсом**. Проект использует архитектуру **RAG (Retrieval-Augmented Generation)** для поиска точной информации в документах и генерации ответов с помощью нейросети, с защитой от галлюцинаций.

##  Возможности
* **Интерактивный веб-интерфейс:** Полноценный отзывчивый чат в браузере на базе `Streamlit`.
* **Верификация ответов:** При каждом ответе ассистент выводит раскрывающийся список первоисточников — точные цитаты из PDF-документа с указанием номеров страниц, позволяя пользователю перепроверить информацию.
* **Защита от галлюцинаций (Prompt Engineering):** Строгое ограничение контекста рамками переданного документа и внедрение специфичных бизнес-правил логики банковских тарифов (например, обработка условий «в прочих случаях»).

##  Архитектура и технические детали
1. **ETL-пайплайн обработки документов (`prepare_data.py`):**
   * Постраничный парсинг сложных PDF-структур с помощью библиотеки `PyMuPDF (fitz)`.
   * Адаптивное разбиение текста на чанки через `RecursiveCharacterTextSplitter` (размер чанка: 600 токенов, перекрытие: 100 токенов для сохранения связности текста на стыках).
   * Векторизация чанков с нормализацией эмбеддингов для ускорения поиска.
2. **Логический бэкенд и семантический поиск (`query_data.py`):**
   * Использование локальной векторной базы данных `ChromaDB`.
   * Текстовые эмбеддинги: `cointegrated/rubert-tiny2` (HuggingFace).
   * Поиск топ-3 наиболее релевантных контекстных фрагментов по косинусному расстоянию.
   * Генерация ответа: интеграция с нейросетью **GigaChat API** через оркестрацию `LangChain`.
3. **Оптимизация UI-слоя (`app.py`):**
   * Кэширование тяжелых глобальных ресурсов (модели эмбеддингов, сессии GigaChat и подключения к ChromaDB) с помощью декоратора `@st.cache_resource`, что предотвращает повторную инициализацию при действиях пользователя.
   
##  Стек технологий
* **Python 3.12**
* **Streamlit** (веб-фреймворк)
* **LangChain** (фреймворк для LLM)
* **ChromaDB** (векторная база данных)
* **HuggingFace / sentence-transformers** (модели эмбеддингов)
* **GigaChat API** (языковая модель)
